## Retrouver et vérifier

```sh
python tools/fetch_upstream.py
python tools/fetch_upstream.py --verify
```

Exécuter ces commandes depuis la racine du laboratoire. Le [manifeste](manifest.json) contient URL, commit, empreinte SHA-256 de l'archive, taille et empreinte de l'arbre extrait. Il est suivi par Git ; les caches `archives/` et `sources/` restent locaux. Après un clone, les liens « Sources » deviennent utilisables après téléchargement. Les archives représentent environ 523 Mio ; les extractions occupent environ 1 Gio. Les sous-modules et objets Git LFS ne sont pas récupérés récursivement par les archives GitHub.

Le script n'installe ni ne lance les firmwares. Les sources existantes ne sont pas écrasées : une différence d'empreinte demande de préserver ses changements avant restauration. Les éventuels nouveaux téléchargements sont vérifiés par rapport aux empreintes existantes avant extraction.

Les projets ne sont pas requalifiés sous la licence MIT du laboratoire. Les mentions et exceptions par fichier restent applicables ; voir [THIRD_PARTY.md](../THIRD_PARTY.md). Les identifiants GPL/AGPL indiquent ici la famille/version du texte présent et ne décident pas à eux seuls d'une clause « ou ultérieure » dans chaque fichier.

## Point d'entrée par usage

- Cardputer seul : `m5cardputer/examples`, `cardputer-demo`, `microhydra`, `microhydra-apps`.
- TV et IR : `irremote/examples`, puis les fonctions IR de `bruce`.
- Badges et RF433 : `rc-switch/examples`, `m5rfid/examples`, `m5rfid-legacy/examples`.
- Wi-Fi/BLE : programmes locaux 04–07/17, puis étude de `bruce` et `evil-cardputer` dans son propre laboratoire.
- Bus et GPS : `bus-pirate`, `tinygpsplus/examples`.
- FM : `rda5807/examples` ; tuner supplémentaire.
- NRF24 : `rf24/examples`, `rf24network/examples` ; adaptation SPI et modules supplémentaires.
- Installation multi-firmware : `launcher` et [le guide français](../docs/experiences/firmwares.md).

Les nombreux forks ou pages citant ces projets ne sont pas des instantanés supplémentaires. Cette sélection ne prétend pas télécharger tous les dépôts existants sur Internet.

## Lire les sources en français

Les sources extraites comportent désormais des commentaires français et **1 125 README créés ou enrichis**, répartis dans les dix-huit projets. Les notices d’origine restent présentes. Le [registre documentaire](documentation-fr/README.md) conserve chaque ajout et permet de retrouver les octets originaux, sans modifier les archives ni leurs empreintes.

Le [sommaire des sources](sources/README.md) donne accès aux guides racines. Chaque répertoire de code indique ses fichiers, ses dépendances, son projet de construction et la manière d’utiliser ses exemples. Les JSON stricts et les formats qui n’acceptent pas les commentaires sont expliqués dans leur README voisin.

```sh
python tools/check_documentation.py
python tools/upstream_documentation.py verify
python tools/fetch_upstream.py --verify
```

Le dernier contrôle reconnaît uniquement les ajouts enregistrés et compare les sources reconstituées aux empreintes amont. Il ignore les métadonnées Finder `.DS_Store`, absentes des archives d’origine ; toute autre modification non prévue reste détectée. `fetch_upstream.py` réapplique aussi les commentaires après une restauration neuve.
