# Sources tierces documentées en français

Après `python tools/fetch_upstream.py`, chaque lien ouvre la notice originale complétée par un guide français. Les sources constituent un cache reconstructible : elles peuvent être absentes après nettoyage ou après un clone. Les octets des archives téléchargées sont vérifiés et les ajouts sont enregistrés dans [documentation-fr](../documentation-fr/README.md).
