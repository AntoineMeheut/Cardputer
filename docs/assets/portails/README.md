Ces captures de navigateur présentent les [pages pédagogiques locales](../../ateliers/portails-fictifs/README.md). Elles ont été conservées lors de la préparation du guide PDF puis copiées ici pour être disponibles après un clone GitHub.

- [Index, 1 280 px](index-1280.png).

Les univers sont fictifs et leurs bandeaux de simulation doivent rester visibles. Ces images ne sont ni des services réels ni des captures d’exécution sur Cardputer. Le générateur PDF utilise les quatre vues de bureau ; son ancienne dépendance au dossier local `build/portails-fictifs/` a été remplacée par ce répertoire versionné.
