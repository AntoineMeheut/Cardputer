# Ateliers HTML locaux

Le sous-projet [portails-fictifs](portails-fictifs/README.md) regroupe trois maquettes et leur index. Ouvrir les fichiers directement dans un navigateur ; aucun serveur ni compte externe n’est nécessaire. Le README du sous-projet détaille le fonctionnement de `details/summary`, les styles intégrés et les limites pédagogiques.
