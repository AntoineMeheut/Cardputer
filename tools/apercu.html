Du projet au premier diagnostic
  1. Créer l’environnement Python, puis installer PlatformIO.
  2. Télécharger les sources aux commits du manifeste.
  3. Compiler le diagnostic avant de connecter un accessoire.
  4. Détecter le port USB réel, puis téléverser.
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python tools/fetch_upstream.py
pio run -e diagnostic
pio device list
pio run -e diagnostic -t upload --upload-port PORT
PORT est une valeur à remplacer. L’image ne représente pas une exécution de ces commandes.
