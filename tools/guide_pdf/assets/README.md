# Sources visuelles et constats de l’édition PDF

- [modulation-ook.png](modulation-ook.png) : capture réelle du navigateur affichant le simulateur HTML, sans émission radio.
- [up-m5cardputer.png](up-m5cardputer.png) : capture d’une fiche documentaire, pas du firmware en fonctionnement.
- [verification-sources-2026-10-17.json](verification-sources-2026-10-17.json) : constat des archives et arbres **avant** ajout des commentaires français aux sources tierces.
- [controle-pdf-2026-10-17.json](controle-pdf-2026-10-17.json) : dimensions, liens, couverture et empreinte de l’édition PDF livrée.

Ces JSON sont des résultats datés, pas des vérifications vivantes. Ne pas les remplacer silencieusement par des résultats d’une autre édition. Le [README du générateur](../README.md) décrit les étapes de régénération.
